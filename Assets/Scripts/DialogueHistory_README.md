# 상담 대화로그

상담 씬의 기존 UI는 수정하지 않습니다. `LastLineWatcher`가 있는 씬을 실행하면 독립된 Canvas에 우측 상단 버튼과 로그 화면을 추가합니다. 씬 파일에 컴포넌트를 추가할 필요가 없습니다.

- 왼쪽 버튼: `Message-Three-Dots_0`, 대화로그 열기
- 오른쪽 버튼: `Gear_0`, 기존 설정창 열기
- 두 버튼은 원본 아이콘만 표시하며 네모 배경과 색상 전환 효과를 사용하지 않습니다.
- 상대방: 왼쪽 프로필·이름·대사, 왼쪽 방향 말풍선 꼬리
- 플레이어: 오른쪽 상담원 프로필·이름·대사, 오른쪽 방향 말풍선 꼬리
- 화자가 없는 지문: 가운데 표시
- 마우스 휠 / 오른쪽 스크롤바: 이전 대화 확인
- ESC / 닫기: 로그 닫기

프로필과 아이콘, 한글 폰트 참조는 `Assets/Resources/DialogueHistoryAssets.asset`에 있습니다. 플레이어는 기존 `기본주인공` 이미지를 그대로 사용합니다. `나`, `상담원`, `플레이어`를 플레이어 화자로 인식합니다.

Yarn이 실제로 전달한 대사를 현재 상담 세션 동안 기록합니다. 움직임 마크업은 표시하지 않고, 선택하지 않은 선택지나 `#raw` 메타데이터는 기록에 추가하지 않습니다. 새 상담을 시작하면 기록을 비웁니다.

설정 또는 로그를 열면 시간과 Yarn 입력을 함께 일시정지합니다. 두 창 사이를 전환해도 일시정지가 유지되고, 마지막 창을 닫으면 원래 시간 배율과 입력 상태로 돌아옵니다. TAB 필터 전환도 창을 연 동안 차단합니다.

## 면담 대사창과 선택지

`DialogueScreenController`와 `InterviewDialogueLayout`이 상담 씬을 실행할 때 면담 UI를 구성합니다. 상대방 대사는 우측 상단, 주인공 대사는 좌측 하단 반투명 패널에 한 문장씩 표시합니다. `나`, `상담원`, `플레이어`, `주인공`, `담당관`을 주인공 화자로 인식합니다. 출력이 완료되면 패널 아래쪽에 다음 표시가 나타납니다. 화자 이름과 기존 한글 폰트를 사용합니다.

선택지가 나오면 대사창을 숨기고 전체 화면에 어두운 반투명 막을 표시합니다. 넓은 선택지 버튼을 화면 중앙에 세로로 배치하고, 선택지 개수와 문장 길이에 맞춰 높이를 조정합니다. 선택하면 막과 선택지가 사라지고 다음 화자에 맞는 위치의 대사창에서 이어집니다.

기존 Yarn `OptionsPresenter`, `OptionItem`, 선택 분기, 인지필터와 정답 강조 컴포넌트를 유지합니다. `InterviewOptionStyle`은 실행 중 생성되는 선택지의 외형만 바꾸고, `InterviewPanelGraphic`은 이미지 파일 없이 패널과 가는 선을 그립니다. 씬 파일과 캐릭터 배경을 따로 교체할 필요가 없습니다.

대사 출력 중 마우스로 클릭하면 현재 문장을 즉시 전부 보여줍니다. 출력이 끝난 뒤 별도로 클릭하면 다음 대사로 넘어갑니다. 선택지·아이템·로그·설정 버튼을 누르는 클릭은 대사 넘기기로 사용하지 않습니다.
