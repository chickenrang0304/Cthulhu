# 크투 양 대사 동작

`Assets/Scenes/CounselScene.unity`의 MonsterAppeance에 동작 컨트롤러와 Yarn 마크업 핸들러가 연결되어 있습니다. Line Presenter의 Event Handlers에도 등록되어 있어 별도의 Inspector 설정 없이 재생할 수 있습니다.

## 대사 안에서 사용

```yarn
크투 양: [talk/]오늘은 뭐 재밌는 거 있어?
크투 양: 진짜? [happy/]좋아! 그거 해보자!
크투 양: [nod/]응. 알겠어.
크투 양: [surprise/]나랑 친구가 되고 싶다고?
크투 양: [angry/]나 안 삐졌거든!
크투 양: [sad/]…역시 너도 돌아갈 거야?
크투 양: 그럼 우리… [romance/]친구야?
크투 양: [still/]그럼 그냥 끝내면 되잖아.
```

8가지 태그는 실제 대사로 출력되지 않습니다. 원하는 단어 앞에 넣으면 그 글자가 나타나는 시점에 실행됩니다. `<romance>` 형태는 지원하지 않으며 `[romance/]`를 사용하세요.

기본 설정에서는 태그가 없는 대사는 움직이지 않습니다. `[talk/]`를 넣은 줄에서만 말하기 리듬이 시작되며, 다음 줄에는 이어지지 않습니다. 지문·상담사 대사·말줄임표만 있는 줄에서는 움직이지 않습니다. 태그 없이도 자동 말하기가 필요할 때만 컨트롤러의 Talk On Untagged Lines를 켜세요. `[still/]`은 그 대사의 나머지 구간을 정지시킵니다.

대사 앞에서 지정하는 명령도 사용할 수 있습니다.

```yarn
<<motion happy>>
크투 양: 좋아! 그거 해보자!
```

이 명령은 바로 다음 대사에서 소비되므로 지문이 끼지 않게 작성하세요. 표정은 기존 `<<expression happy>>` 명령으로 별도 지정합니다. `sad`는 몸이 내려앉는 동작이며, 없는 슬픈 표정을 새로 생성하지 않습니다.

## 크기와 타이밍

MonsterAppeance의 Character Motion Controller에서 Talk Height, Happy Height 등으로 강도를 바꿀 수 있습니다. 크기는 1920×1080에서의 화면 픽셀 기준이고, 실제 카메라 해상도와 부모 Transform 배율에 맞춰 변환됩니다. 월드 좌표를 정수로 반올림하는 DOTween snapping은 사용하지 않습니다.

일반 말하기는 작은 상하 움직임과 짧은 쉼을 반복합니다. 문장부호에서는 잠깐 쉬고, 글자 출력이 끝나면 정착합니다. 감정 반응은 한 번 실행되어 글자가 먼저 다 나와도 동작은 착지까지 마칩니다. 다음 대사로 넘기면 즉시 취소됩니다.

대사 스킵·선택지·대화 종료·비활성화·TAB 전환 때에는 동작을 취소하고 원래 위치로 복귀합니다. TAB으로 돌아온 같은 대사의 반응을 다시 실행하지 않습니다. 본모습에는 귀여운 말하기 동작을 적용하지 않습니다. 설정 창에서 Time.timeScale이 0이 되면 DOTween도 멈춥니다.

본 기능의 동작은 위치 이동만 사용합니다. 머리·입·촉수를 따로 움직이는 리깅은 포함하지 않습니다.
